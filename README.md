## 数据集概述

本数据集专注于**自然与人工光照条件下不同成熟度番茄果实的多模态视觉检测与分割**，服务于智慧农业、自动化采摘及果实品质评估。数据涵盖可见光、深度图与近红外三种模态，适配目标检测与语义分割等多任务应用。

## 数据三要素解析

**类别与任务覆盖**
*   数据集定义 **3** 类番茄成熟度：**未熟**、**半熟**、**成熟**，直接服务于采摘决策。
*   同时提供**目标检测**（边界框）与**语义分割**（像素级掩膜）两种标注，支持从粗定位到精细轮廓提取的多层次任务。

**数据规模与模态**
*   数据包含 **4000** 组多模态样本，涵盖可见光、深度图、近红外三种模态，总数据量约 **10.08 GB**。
*   图像分辨率统一为 **1280×720**，画质清晰。
*   数据在**自然光、人工光、微弱光、钠黄光** 4 种光照条件下采集，场景多样性极强，能大幅提升模型在复杂真实环境下的泛化能力。

**格式与结构**
*   按模态分类存储：`RGB`（可见光）、`Depth`（深度）、`Infrared`（近红外），文件为 PNG 格式。
*   标注文件分为 `annotationsXML`（目标检测）与 `annotationsJSON`（语义分割），数据结构规范，便于直接接入主流框架训练。

## 知识普及：多模态农业视觉检测的技术要点

*   **多模态互补价值**：
    *   **可见光**：提供丰富的颜色与纹理信息，是成熟度判断的主要依据。
    *   **深度图**：提供三维空间信息，有助于分离重叠果实，辅助机械臂精准定位与抓取。
    *   **近红外**：对光照变化不敏感，能穿透部分遮挡，在微弱光或复杂光照下提供稳定的目标特征。
*   **光照鲁棒性**：钠黄光等人工光源会改变果实的表观颜色，单纯依赖可见光的模型容易失效。融合近红外或深度信息，可构建对光照变化更鲁棒的检测系统。
*   **遮挡与重叠**：田间番茄常被枝叶遮挡或相互重叠，语义分割能提供精细轮廓，有助于区分相邻个体。
*   **应用闭环**：检测与分割结果可结合深度信息，直接输出三维空间坐标与成熟度标签，指导机械臂执行“识别-定位-采摘”的自动化闭环。

## 快速开始（代码示例）

**1. 准备配置文件 (`data.yaml`)**
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 3
names: ['未熟', '半熟', '成熟']
```

**2. 启动 YOLOv8 语义分割训练**
```python
from ultralytics import YOLO

model = YOLO('yolov8m-seg.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=8,
    device=0
)
```

**3. 多模态融合提示**
可将 RGB 图像与深度/近红外图像在通道维度拼接，或分别提取特征后进行融合，以充分利用多模态信息。
